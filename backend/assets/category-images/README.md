# Картинки плиток категорий

120 картинок WebP с прозрачным фоном: 9 разделов верхнего уровня и 111 подкатегорий.
Имя файла совпадает с адресом категории: `pickles.webp` — для «Солений».
Размер — до 480 × 360 px. Сгенерированы нейросетью, запросы лежат в `prompts.json` и `launch-prompts.json`.

Привязать их к категориям на новом сервере (из папки `backend`):

```powershell
python -m alembic upgrade head
python -m scripts.import_category_images
```

Скрипт копирует картинки в `MEDIA_DIR/categories` и записывает путь в `categories.image_path`.
Картинки, которые уже заданы, он не трогает. Дальше картинки меняют в «Админка → Категории».

Файлы лежат в медиа, а связь с категорией — в базе. При переносе сервера переносите и базу, и медиа.
Сами категории, атрибуты и единицы приходят миграцией 0018 из снимка `migrations/data/launch_catalog_v1.json`.
