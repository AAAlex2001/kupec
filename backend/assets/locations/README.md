# Каталог населённых пунктов

Источник: официальная выгрузка КЛАДР ФНС от **02.10.2026**:
https://fias-file.nalog.ru/downloads/2026.10.02/base.7z

`russia.csv.gz` содержит 159 795 действующих адресных записей населённых пунктов
из всех 89 регионов, представленных в выгрузке. Включены города федерального
значения, города, посёлки, деревни, сёла, хутора, станицы, станции и другие
типы населённых пунктов из классификатора. Сохранены также СНТ, присутствующие
на уровне населённых пунктов в КЛАДР.

Включаются записи с кодом актуальности `00`. Исторические названия, удалённые
записи, административные районы, сельсоветы и элементы планировочной структуры
не предлагаются как отдельные населённые пункты. Код `99` (Байконур) исключён.
Покрытие соответствует этой выгрузке; каталог не обновляется из ФНС в реальном
времени. Контрольные суммы, дата источника и количество записей по регионам
хранятся в `metadata.json`.

## Подготовка новой версии

1. Скачать актуальную выгрузку по ссылке `Kladr47ZUrl` из
   https://fias.nalog.ru/WebServices/Public/GetLastDownloadFileInfo.
2. Распаковать только `KLADR.DBF` и `SOCRBASE.DBF` в временный каталог.
3. Из корня репозитория выполнить:

   ```powershell
   python backend/scripts/build_location_catalog.py <каталог-с-DBF> --date YYYY.MM.DD
   ```

Исходные DBF и полный архив не включаются в репозиторий или Docker-образ.
Сборщик использует стандартную библиотеку Python; установка дополнительных
пакетов для работы сайта не требуется.

## Применение

Первый импорт выполняет миграция `0037` при штатном деплое. Она сохраняет ID
существующих пунктов и ссылки из объявлений и профилей. Старый пункт получает
код КЛАДР, только если запись в каталоге однозначна. Неоднозначный старый пункт,
у которого в каталоге есть тёзки, удаляется, если на него не ссылаются объявления
и профили, иначе остаётся без кода. Пункты, которых нет в КЛАДР, сохраняются.
Повторный импорт не добавляет копии записей с тем же кодом КЛАДР.

После обновления файла каталога для уже работающей базы выполнить:

```sh
docker compose run --rm --no-deps backend python -m scripts.import_locations
```
