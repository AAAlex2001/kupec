# Ещё 30 городских статей

30 новых материалов раздела «Новости»: самостоятельные темы, 7–9 тысяч знаков видимого текста, SEO-заголовки и описания. Все 30 обложек созданы встроенным ImageGen отдельно, с разными сюжетами, ракурсами и палитрами. Запросы генерации сохранены в `cover_source.prompt` каждого JSON. Готовые WebP находятся в `backend/assets/article-covers/`, имена совпадают со slug статей.

Штатный `./deploy.sh` применяет миграцию `0040_more_city_news` и запускает существующий импорт обложек. Статьи появляются в новостях и админке, опубликованные страницы входят в динамический sitemap. Повторная загрузка сохраняет существующие статьи и обложки, отредактированные в админке.

При ручном обновлении после сборки новых образов:

```sh
docker compose run --rm migrate
docker compose run --rm --no-deps backend python -m scripts.import_article_covers
```
