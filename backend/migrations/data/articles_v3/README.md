# 70 городских статей для новостей

Готовый пакет: 70 самостоятельных материалов для 70 городов России и 70 разных обложек. Объём каждой статьи — 7 000–9 000 знаков видимого текста с пробелами. В JSON находятся текст, заголовок, описание, SEO-метаданные и сведения об обложке. Темы перечислены в `editorial-plan.json`.

## Обложки

Готовые WebP лежат в `backend/assets/article-covers/`, имя файла совпадает со slug статьи. 21 иллюстрация создана встроенным ImageGen, 49 фотографий получены с Wikimedia Commons. Поле `cover_source` сохраняет запрос генерации либо страницу источника, автора и лицензию фотографии. Миграция добавляет видимую подпись с атрибуцией в конец статьи. Фотографии обозначены как тематические иллюстрации.

## Загрузка на сервер

После пуша обычный запуск `./deploy.sh` соберёт новые образы, выполнит миграцию `0038_city_news` и импортирует обложки. Дополнительная команда для этого пакета не нужна.

Миграция добавляет статьи в раздел новостей со статусом публикации. Они доступны в админке и попадают в существующий динамический sitemap. Повторный запуск пропускает уже существующие slug и сохраняет редакторские изменения.

Если используется другой процесс деплоя, после обновления образов нужно выполнить миграции и существующий импорт обложек:

```sh
docker compose run --rm migrate
docker compose run --rm --no-deps backend python -m scripts.import_article_covers
```

## Проверки

`tests/test_city_news_seed.py` проверяет количество, уникальность городов и метаданных, объём текста, структуру разделов, внутренние ссылки, лицензии и наличие разных обложек. Проверены повторный запуск миграции, сохранение редакторских изменений и откат. `tests/test_article_covers.py` проверяет весь каталог из 100 обложек и их импорт.
